# Расписание НГПУ для группы 3.024.2.23 (ИОДО)

Автоматизированный сервис синхронизации расписания занятий студентов Института открытого и дистанционного образования (ИОДО) НГПУ. Проект включает в себя парсер официального расписания, генератор календаря в формате iCalendar (`.ics`), а также адаптивный веб-виджет, развернутый на GitHub Pages.

---

## 📅 Возможности

- **Парсинг расписания**: разбор сетки пар осеннего семестра (1–13 недели) и экзаменационной сессии.
- **Поддержка iCalendar (.ics)**: экспорт событий с указанием времени, аудитории, типа занятия и преподавателя.
- **Веб-виджет**: интерактивный просмотр расписания с фильтрацией по неделям и дням.
- **Синхронизация**: подписка на календарь с автообновлением в Apple Calendar и Google Calendar.

---

## 📱 Инструкция по подключению расписания

### 🍏 Apple Calendar (iOS / iPadOS / macOS)
1. Откройте веб-виджет расписания и нажмите кнопку **«Подписаться в Apple Calendar»** (откроется ссылка с протоколом `webcal://`).
2. Либо добавьте вручную:
   - **macOS**: приложение *Календарь* → *Файл* → *Новая подписка на календарь...*
   - **iOS / iPadOS**: *Настройки* → *Календарь* → *Учетные записи* → *Добавить учетную запись* → *Другое* → *Подписной календарь*.
3. В поле адреса вставьте ссылку:
   `webcal://<пользователь>.github.io/<репозиторий>/schedule-nspu.ics`
4. Включите автообновление (рекомендуется: каждый день или каждый час).

### 🤖 Google Календарь (Android / Web)
1. Нажмите в виджете кнопку **«Подписаться в Google Календарь»** для быстрого добавления в один клик.
2. Либо перейдите в веб-версию [Google Calendar](https://calendar.google.com):
   - В левой панели нажмите значок **«+»** рядом с разделом *«Другие календари»*.
   - Выберите пункт **«Добавить по URL»**.
   - Вставьте ссылку: `https://<пользователь>.github.io/<репозиторий>/schedule-nspu.ics`
   - Нажмите **«Добавить календарь»**. Расписание синхронизируется на всех ваших устройствах.

### 🔗 Прямая ссылка на файл (.ics)
- Прямой URL: `https://<пользователь>.github.io/<репозиторий>/schedule-nspu.ics`
- Копирование ссылки позволяет импортировать расписание в Microsoft Outlook, Mozilla Thunderbird и другие календарные приложения.

## 💻 Локальный запуск парсера

Для ручного обновления расписания или локальной разработки:

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Запустите скрипт парсера:
   ```bash
   python parser.py
   ```
3. Скрипт скачает актуальные данные с сайта НГПУ, сформирует файлы `schedule-nspu.ics` и `schedule.json`, а также скопирует файл календаря в папку «Загрузки».

---

## ⚙️ Автообновление (GitHub Actions & Pages)

В репозитории настроен CI/CD пайплайн (`.github/workflows/update.yml`):
- Запуск по расписанию: **ежедневно в 22:00 по Новосибирску** (15:00 UTC / cron: `0 15 * * *`).
- Возможность ручного запуска через `workflow_dispatch`.
- Свежие файлы расписания автоматически публикуются на GitHub Pages, поэтому подписанные календари обновляются у пользователей без необходимости повторной настройки.
